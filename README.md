# my-notes
Cette application sert à la prise de notes avec des fichiers au format Markdown.

Le but est simple : conserver une structure classique de dossiers et de fichiers Markdown, directement dans le stockage de l'application.

Pour le contrôle d'accès, l'application intègre uniquement une authentification 2FA afin de simplifier la connexion tout en sécurisant l'accès au dashboard web permettant de gérer les notes.
